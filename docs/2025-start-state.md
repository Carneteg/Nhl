# Startläge 2025

Standarddatum är `2025-07-01`, fas `FREE_AGENCY`, lag Edmonton Oilers. `bootstrap:2025 --team ALL` arkiverar aktiva simulationer, tar bort gamla alternativa canon-lås och återskapar samtliga 32 verkliga lag från NHL:s 2025–26-säsongsdata. Alternativa startpunkter anges som ISO-datum; fas härleds centralt och lagras tillsammans med simulation-ID, säsong och dag. `simulation:new` kopierar därefter real baseline, skapar inkorg, nyhet och GM-intro. Den importerar aldrig tidigare alternativhistorik.
