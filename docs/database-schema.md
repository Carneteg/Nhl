# Databasschema

`nhlgm/schema.sql` definierar players, teams, contracts, roster assignments, player simulation state, rights via rights owner, draft picks/classes/rankings, scouting, transactions, negotiations, games/stats, injuries, waivers, staff, GMs, inbox/news/events, sources, conflicts, locks och simulation state. Unika constraints stoppar dubbletter, två aktiva NHL-uppdrag och dubbelt ägande av samma originalval.
