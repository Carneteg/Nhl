# Canon och konflikter

`canon_locks` låser ett specifikt entity/field/value i en simulation. Automatiska importer uppdaterar aldrig `simulation_players`, `roster_assignments` eller simulationshändelser. Vid lägre prioriterat nytt värde behålls gammalt värde och `data_conflicts` visar båda värdena, källorna, prioriteter och rekommenderad manuell åtgärd. Ett GM-beslut måste vara explicit och loggas innan simulationens canon ändras.
