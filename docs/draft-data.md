# Draftdata

Draftspelare klassificeras som `VERIFIED_REAL`, `EARLY_CANDIDATE`, `INCOMPLETE_SCOUTING` eller `GENERATED_FUTURE_PROSPECT`. Generering är förbjuden så länge identifierbara verkliga spelare finns och genererade namn får aldrig maskeras som verkliga. Rankings versionslagras separat från intern scouting så historik inte försvinner. Den medföljande 2025/2026-fixturen är endast ett verifierbart minimiurval, inte en komplett draftklass.
